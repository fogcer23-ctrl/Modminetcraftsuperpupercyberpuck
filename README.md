# Cybernetic Augmentation 0.1.0

Мод для **Minecraft 1.21.1 + NeoForge 21.1.259**, требуется **Java 21**.

## Скачать

- [Скачать JAR](https://github.com/fogcer23-ctrl/Modminetcraftsuperpupercyberpuck/raw/refs/heads/downloads/cybernetic_augmentation-0.1.0.jar)
- [Скачать ZIP с тем же JAR](https://github.com/fogcer23-ctrl/Modminetcraftsuperpupercyberpuck/raw/refs/heads/downloads/cybernetic_augmentation-0.1.0-download.zip)

Поместите JAR в папку `mods` профиля NeoForge. ZIP сначала распакуйте. Для сетевой игры установите одинаковый JAR на клиент и сервер.

23 типа имплантов пяти уровней качества, хирургическая станция, энергия, перегрев, активные способности и HUD. **K** — управление имплантами; ПКМ по станции — установка.

Это первая версия. Сборка, 39 модульных тестов и 6 игровых серверных тестов прошли. Графический клиент и игра с несколькими настоящими клиентами пока не проверены.

Контрольные суммы находятся в `SHA256SUMS.txt`.
